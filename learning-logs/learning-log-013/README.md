# 📚 Learning Log #013

## 🎯 Topic
Web APIs — `setInterval`, `setTimeout`, and `clearInterval`

---

## 📝 Overview
This log covers timer-based Web APIs by building a simple live clock. It uses `setInterval` to update the display every second, `setTimeout` to auto-stop the clock after a fixed duration, and `clearInterval` to cancel a running timer — both automatically and via a manual "Stop" button.

---

## 📖 What I Learned
- Used `setInterval` to repeatedly update the clock display every second
- Used `setTimeout` to automatically stop the clock after 10 seconds
- Used `clearInterval` to cancel the running interval, both from the timeout and from a manual stop button
- Practiced wiring DOM elements (`querySelector`, `addEventListener`) to control the timers

Built with `index.html`, `style.css`, and `script.js` — run by opening `index.html` in a browser.

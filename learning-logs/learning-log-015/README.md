# 📚 Learning Log #015 — DOM, JSON & Event Bubbling

## 🎯 Topic

**DOM Manipulation, JSON Data, Dynamic HTML Rendering & Event Bubbling**

## 📝 What I Learned

Today I practiced connecting JavaScript with HTML using JSON-like data, DOM manipulation, and dynamic HTML rendering. I worked with an array of user objects containing details such as name, role, status, rating, hours, and profile images.

I also practiced **event bubbling** by attaching a click event to the main container and using `event.target` to identify the clicked button. The user's status can be changed between **Stranger → Friend**, and the UI is rendered again to reflect the updated state.

## 💻 What I Built

I built a small **user profile card interface** where JavaScript dynamically generates cards from the data and inserts them into the DOM.

Each card displays profile information, online/offline status, ratings, hours, months, and an **Add Friend / Remove Friend** button.

## 🧠 Key Takeaways

- Practiced rendering data dynamically with JavaScript.
- Learned how JavaScript can generate HTML elements from data.
- Practiced DOM manipulation using `innerHTML`.
- Understood the basic idea of event bubbling.
- Used `event.target` to identify the clicked element.
- Practiced updating data and re-rendering the UI.
